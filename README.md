# dns-exfil-hunter

DNS is allowed out of almost every network, which makes it a favourite channel for tunneling and data exfiltration. dns-exfil-hunter reads query logs and ranks the clients and domains whose DNS traffic looks like a tunnel or a domain generation algorithm (DGA), with the reasons.

**Live demo:** https://jvch0512.github.io/dns-exfil-hunter/ (a report on synthetic queries)

Python 3.10+, standard library only, offline.

## Use

```bash
python -m dns_exfil_hunter examples/queries.csv                  # text report
python -m dns_exfil_hunter queries.csv --html > report.html      # shareable report
python -m dns_exfil_hunter queries.csv --json
python -m dns_exfil_hunter queries.csv --allow cdn.example --min-score 70
python -m dns_exfil_hunter queries.csv --fail-on-find            # exit 1 in scheduled hunts
```

Input is CSV with `ts,client,qname,qtype` and optionally `rcode`. Resolver logs (BIND, Unbound, Windows DNS, Zeek `dns.log`) convert with a one-line `awk` or `jq`. Sample: [examples/queries.csv](examples/queries.csv), regenerated by [examples/make_sample.py](examples/make_sample.py). Output: [docs/sample-output.txt](docs/sample-output.txt).

## What it measures

Per client and registered domain: subdomain length, Shannon entropy of the leftmost label, share of names that look hex, base32 or base64 encoded, share of TXT, NULL, CNAME and MX queries, how many queries use a new name, and the query rate. Per client across domains: bursts of NXDOMAIN answers for random-looking second-level names (DGA).

## Limits

- Candidates, not verdicts. CDNs, anti-virus and email security services legitimately use long encoded names. The sample shows one as a false positive on purpose: allowlist it with `--allow`.
- Low-and-slow tunnels with short labels and few queries will not cross the threshold. Lower `--min-queries` and `--min-score`, and combine with passive DNS and EDR data.
- Registered-domain detection uses a short built-in list of two-level suffixes, not the full public suffix list.

## Where it fits

SOC hunts, MDR services, incident response triage and purple-team debriefs. A natural scheduled deliverable: run weekly over resolver exports and send the HTML report.
